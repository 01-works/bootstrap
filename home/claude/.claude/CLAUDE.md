# User Preferences

- Respond in Korean by default.

## Browser work

- 개발 화면과 UI 흐름 검증은 Paseo Browser를 우선한다. 기존 Chrome의 로그인·탭이 필요한 작업은 `agent-browser` 스킬을 읽고 실행 중인 Chrome에 연결한다. 이 사용자 선택 기준은 스킬의 일반적인 도구 우선순위보다 우선한다.
- Chrome 직접 연결에는 작업별 고유 `--session`, `--auto-connect` 또는 확인된 `--cdp`, `--pin-tab`을 사용한다. `--profile 이름`은 프로필 복사 방식이므로 직접 연결의 대체로 간주하지 않는다.
- 지정된 브라우저에 연결할 수 없으면 이유를 알린다. 인증이 필요한 작업을 임시·테스트 브라우저로 임의 대체하지 않는다. 연결 허용 창은 사용자에게 알린다.
- 담당 탭만 조작하고 같은 탭의 병렬 조작을 피한다. 공유 프로필에서 로그인·로그아웃 등 인증 상태를 바꾸는 작업은 조율한다. 검증하지 못한 항목은 미검증으로 보고한다.
