# 장비 고르기

모델 이름과 가격은 금방 바뀌므로 여기에는 판단 기준만 적는다. 살 때의 구체적인 사양은 기기별 문서에 기록한다.

## 먼저 정할 것: 이 기기의 역할

| 역할 | 맞는 기기 | 이유 |
|---|---|---|
| 늘 켜두고 에이전트·서버·원격 접속용 | Mac mini | 작고 조용하고 전기를 적게 먹는다 |
| 무거운 빌드, 로컬 모델, 에이전트 여러 개 동시 실행 | Mac Studio | 메모리를 크게 올릴 수 있고 발열 여유가 있다. 메모리를 크게 올리려고 사는 기기이니 여기서 아끼지 않는다 |
| 이동하며 작업 | MacBook Pro/Air | 메인 기기에 원격으로 붙는 용도면 `minimal` 프로필로 충분 |

## 사양 우선순위

1. **메모리** — 나중에 늘릴 수 없다. 가장 먼저 예산을 쓴다.
   - 지금 Mac mini(16GB) 기록 (2026-10-06): colima VM 하나에 8GB를 주고 에이전트를 여러 개 돌리는 상태에서 **스왑 9.2GB 중 8.7GB 사용**. 16GB는 이 사용 방식에 부족하다.
2. **저장 공간** — 외장 SSD로 보완은 되지만 Docker 이미지, `node_modules`, 모델 파일은 내장 디스크에 두는 게 편하다.
   - 지금 Mac mini(256GB) 기록 (2026-10-06): 228GB 중 **168GB 사용, 27GB 남음 (87%)**. 256GB도 부족하다. 다음 메인 개발기는 최소 1TB.
3. **칩** — 같은 세대 안에서는 메모리·저장 공간보다 체감 차이가 작다.
4. **포트·네트워크** — 늘 켜두는 기기라면 10Gb 이더넷 옵션을 볼 만하다.

기기가 둘 이상이 되면 역할에 맞게 프로필을 나눈다. 예를 들어 Mac Studio를 메인으로 쓰고 Mac mini를 서버로 남기면 Mac Studio가 `main`, Mac mini는 새 프로필이다.
