# 브라우저 도구 선택 기록

2026-10-18~19, 같은 Mac에서 진행한 표본 시험의 요약이다. **현재 선택은 Browser Use CLI**이며, 설치·작업 방법은 [운영 지침](browser.md)을 따른다. 이 문서는 이전 도구를 설치하거나 다시 비교하라는 지침이 아니다.

## 선택 근거

기존 Chrome의 인증 프로필을 사용하고, 같은 연결을 여러 작업에서 순차 재사용하는 요구에 맞춰 선택했다. Browser Use의 공식 CLI로 기존 연결 재사용·작업자 인계·공개 화면 조작을 확인했다. 프로필 지정만으로 로그인 유효성이나 새 연결의 승인 생략이 보장되지는 않는다.

| 당시 도구 | 확인한 범위 | 남은 한계 |
|---|---|---|
| Browser Use 0.13.11 / harness 0.1.13 | 명시 WS로 공식 CLI 연결 성공. 기존 daemon 재사용 중 추가 Allow 없이 공개 화면 snapshot·PNG·탭 정리 5/5 성공. 인증 관리 UI 구조 전후 확인 | 기본 local 자동 발견 실패 이력. 서버 인증 유효성·재부팅 후 재연결·장기 안정성 미검증 |
| agent-browser 0.39.1 | 사용자 Allow 보고 후 공식 CLI로 공개 3과제 두 회차 완료. 후속 기존 daemon의 공식 IPC로 공개 화면 5/5 성공 | 이전 연결 결과 불명·timeout 기록 유지. IPC 시험을 native CLI 성능으로 해석하지 않으며 당시 실제 정책 적용은 미확인 |
| Aside 앱 1.0.928.1 / CLI 1.26.1015.732 | 데스크톱 공개 3과제 두 회차 완료, 후속 snapshot·PNG 5회 성공 | 기존 Chrome과 별도 로그인 환경. 390px·로그인 지속성 미검증. client 종료 뒤 담당 target 소멸 관측 |
| Paseo Browser 0.11.2 | 공개 3과제 성공 회차 존재. 후속 탭 생성·snapshot·정리 확인 | 캡처 실패와 성공이 반복됨. 후속 시험 캡처 10회 모두 `screenshot_no_frame`. 원인 미확정 |

## 해석 범위

- 실행 순서·캐시·승인 대기·연결 상태·조작 경로가 달라 일반적인 속도·신뢰도 순위를 매기지 않았다. Browser Use의 직접 CDP 문서 링크 활성화 실패는 공식 클릭 helper 결함으로 귀속하지 않는다.
- 짧은 RSS 관측에는 공유 브라우저·동시 작업 영향이 있어 메모리 누수나 도구별 메모리 순위를 판정하지 않았다.
- 공개 화면·인증 UI 표본 확인이며 가입·결제·전체 기능 또는 장기 인증 지속성을 검증한 결과가 아니다. 이전 실패를 후속 성공으로 지우지 않았다.
- 소유 탭 정리와 닫힌 target의 오류는 확인했지만, 모든 재시작·유령 상태를 검증한 것은 아니다.

당시 원본 집계는 로컬 임시 경로의 `browser-fair-pilot-20261019/audit/final-metrics-after-consent.json`과 `browser-ops2-20261019/summary.json`에 있다. 임시 파일은 삭제될 수 있으므로 지속 보존되는 결론과 한계는 위 요약을 기준으로 한다. 실행 로그·개인 계정·프로필 데이터는 저장소에 옮기지 않는다.
