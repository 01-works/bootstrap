# Claude Code

## 설치

`agents` 단계가 공식 설치 스크립트로 설치한다. `~/.local/bin/claude`에 설치되고 스스로 업데이트된다. Homebrew cask(`claude-code`)는 자동 업데이트가 안 되고 최신보다 한 주쯤 늦어서 쓰지 않는다 ([TOOLS.md](../TOOLS.md)).

설치 상태 점검: `claude doctor`

## 설정

| 파일 | 저장소 | 내용 |
|---|---|---|
| `~/.claude/CLAUDE.md` | [링크](../home/claude/.claude/CLAUDE.md) | 모든 프로젝트 공통 지시 (한국어, 브라우저·GUI 작업 원칙). Codex `AGENTS.md`와 같은 파일 |
| `~/.claude/settings.json` | [초기 기본값](../home/claude/.claude/settings.json) | 모델, 권한, 알림. 기기 로컬 일반 파일 |
| `~/.claude/skills/` | 넣지 않음 | Paseo·Browser Use가 설치하는 스킬, 동기화되는 스킬. 직접 만든 스킬만 `agents/skills/`에서 링크 |
| 그 외 `~/.claude/*` | 넣지 않음 | 세션, 기록, 캐시, 플러그인 |

저장소의 `home/claude/.claude/settings.json`은 새 기기 초기값이며 링크하지 않는다. 기존 `.seed` 처리와 같이 설정 파일이 없을 때만 복사한다. 기존 일반 파일은 그대로 두며, Claude Code가 저장하는 설정·플러그인 변경은 이 기기에만 남는다. 전환을 마친 기기 사이의 자동 설정 동기화는 끝난다. 공통 초기 기본값을 바꾸려면 저장소의 `settings.json`을 직접 고쳐 커밋한다. 기존 기기에 전파하려는 값은 각 기기의 로컬 파일에 따로 적용한다.

기존 기기는 설정 링크를 한 번 수동 전환해야 한다. 자동 갱신(`update --auto`), 일반 설치, 기본 `--only dotfiles`는 링크를 교체하지 않고 기존 수동 작업 대기(pending)로 남긴다. 다른 단계와 저장소 갱신은 계속 진행한다.

Claude Code를 **모두 종료하고 전환이 끝날 때까지 새로 실행하지 않는 동안**, 다른 도구의 터미널에서 실행한다. Claude Code 세션 안에서는 실행할 수 없다.

```sh
./bootstrap.sh --only dotfiles --migrate-claude-settings
./bootstrap.sh update   # 전환 뒤 남아 있는 dotfiles pending 정리
```

수동 명령은 실행 직전에 실행 파일 이름이 `claude`인 프로세스를 검사한다. 하나라도 있거나 프로세스 목록을 읽지 못하면 전환을 거부한다. 조건을 통과하면 같은 디렉터리의 임시 파일에 현재 내용을 복사하고 `~/.local/state/bootstrap/backup/<시각>-<번호>/.claude/settings.json`에 일반 파일로 백업한다. 경로가 여전히 같은 대상을 가리키는 링크이고 내용도 복사본과 같은지 확인한 뒤 교체하고, 전환이 끝난 뒤 백업과 내용이 같은지 검증한다. 교체 전 변경을 감지하면 최신 저장을 유지하고 보류한다. 백업은 보존한다.

프로세스 검사는 검사 이후의 새 실행이나 다른 도구의 설정 쓰기까지 막지는 않는다. 마지막 비교와 교체도 별도 연산이므로, 위의 실행 조건을 지켜야 한다. 전환 후 내용 검증에 실패하면 현재 파일과 백업을 그대로 두고 오류를 알린다.

저장소 파일 이름은 유지한다. 따라서 전환이 지연돼도 링크가 끊어지지 않지만, 전환 전까지 Claude Code의 저장이 저장소에 반영돼 갱신 보류가 다시 생길 수 있다. 같은 저장소 파일의 원격 값 변경도 기존 링크를 통해 반영되며, 수동 전환은 그 시점의 현재 내용을 유지한다. 전환 자체는 모델·권한·테마 값을 바꾸지 않는다. 실제 값 변경이 저장소에 남아 있으면 자동 갱신은 기존 정책대로 보류하므로, 사용자 변경을 먼저 별도로 보존·정리해야 한다.

내용을 되돌리려면 백업을 로컬 `~/.claude/settings.json`에 복사한다. 링크 방식까지 되돌리려면 저장소를 이전 버전으로 복구하고 현재 로컬 파일을 별도 백업한 뒤 `dotfiles` 단계를 실행한다.

## 로그인
