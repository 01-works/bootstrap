## 설정 도우미

- [ ] 언어·지역: 한국어, 대한민국
- [ ] Wi-Fi 또는 이더넷 연결
- [ ] Apple 계정 로그인
- [ ] FileVault 켜기. 복구 키를 Apple 계정에 맡길지 따로 보관할지 정하기

- [ ] Touch ID (해당 키보드가 있을 때)

## 데스크톱에 들어와서

- [ ] 소프트웨어 업데이트 최신으로
